- [Companies Screener](https://docs.sectors.app/api-references/v2/indonesia/screener/companies.md): High-performance API for filtering and sorting IDX-listed companies. Supports both structured SQL-like queries (`where`, `order_by`) and natural language queries (`q`). Returns a paginated list of companies.
- [Free Float Market Analysis](https://docs.sectors.app/api-references/v2/indonesia/screener/free-float.md): Returns the free float percentage for IDX-listed companies, optionally filtered by one level of the sector taxonomy. Results are ordered by `free_float` descending.
- [Companies with Revenue Segments](https://docs.sectors.app/api-references/v2/indonesia/helper-list/companies-segments-list.md): Returns a dictionary of all companies that have revenue and cost segment data available, along with their available financial years.
- [Latest Quarterly Financial Dates (Universe)](https://docs.sectors.app/api-references/v2/indonesia/helper-list/latest-quarterly-dates.md): Returns the **latest** available quarterly report date (and its quarter label) for **every** IDX company in one paginated feed — instead of calling the per-symbol [Quarterly Financial Dates](https://docs.sectors.app/api-references/v2/indonesia/helper-list/company-quarterly-dates) helper once per tic…
- [Quarterly Financial Dates](https://docs.sectors.app/api-references/v2/indonesia/helper-list/company-quarterly-dates.md): Returns all available quarterly financial report dates for a given symbol, grouped by year. Use the `report_date` values returned here as inputs to the `report_date` parameter in the Quarterly Financials endpoint.
- [Industries](https://docs.sectors.app/api-references/v2/indonesia/helper-list/industries.md): Returns all available subsector/industry pairs as kebab-case slugs. Use these values as inputs to the `industry` parameter.
- [Subindustries](https://docs.sectors.app/api-references/v2/indonesia/helper-list/subindustries.md): Returns all available industry/sub-industry pairs as kebab-case slugs. Use these values as inputs to the `sub_industry` parameter.
- [Subsectors](https://docs.sectors.app/api-references/v2/indonesia/helper-list/subsectors.md): Returns all available sector/subsector pairs as kebab-case slugs. Use these values as inputs to `sector` and `sub_sector` parameters.
- [News Tags](https://docs.sectors.app/api-references/v2/indonesia/helper-list/tags.md): Returns a sorted alphabetical array of all available tag slugs used across news articles and company filings. Use these values as inputs to the `tags` parameter.
- [Corporate Actions](https://docs.sectors.app/api-references/v2/indonesia/company/corporate-actions.md): <Note>IDX symbol: 4 letters, optionally followed by `.jk` (case-insensitive). E.g. `BBCA`, `BMRI`, `TLKM`.</Note>
- [Company Revenue Segments](https://docs.sectors.app/api-references/v2/indonesia/report/company-segments.md): Returns a Sankey-graph-ready revenue and cost segment breakdown for a given company and financial year. Not all companies have segment data — use the [Companies with Revenue Segments](https://docs.sectors.app/api-references/v2/indonesia/helper-list/companies-segments-list) endpoint to check availabi…
- [Company Report](https://docs.sectors.app/api-references/v2/indonesia/report/company-report.md): Returns a comprehensive company report organized into distinct sections. By default all sections are included. Use `sections` to request only the data you need and reduce response size.
- [Shareholders Composition](https://docs.sectors.app/api-references/v2/indonesia/company/shareholders-composition.md): <Note>IDX symbol: 4 letters, optionally followed by `.jk` (case-insensitive). E.g. `BBCA`, `BMRI`, `TLKM`.</Note>
- [Company Quarterly Financials](https://docs.sectors.app/api-references/v2/indonesia/report/quarterly-financials.md): Returns quarterly financial data for a given IDX symbol. Fields vary by sector — financial-sector companies (banks, insurance) have additional metrics like `net_interest_income`, `gross_loan`, `total_deposit`.
- [Subsector Report](https://docs.sectors.app/api-references/v2/indonesia/report/sector-report.md): Returns a comprehensive report for an IDX subsector, organized into distinct sections. Use `sections` to fetch only the data you need.
- [Daily Full-Universe Close](https://docs.sectors.app/api-references/v2/indonesia/transaction/close.md): Returns the daily closing price for **every** IDX ticker on a single trading day, in one paginated feed — instead of calling the per-symbol [Daily Transaction Data](https://docs.sectors.app/api-references/v2/indonesia/transaction/daily) endpoint once per ticker.
- [Daily Transaction Data](https://docs.sectors.app/api-references/v2/indonesia/transaction/daily.md): Returns daily close price, volume, and market cap for a given IDX symbol over a date range of up to 90 days.
- [IDX Market Summary](https://docs.sectors.app/api-references/v2/indonesia/transaction/idx-total.md): Returns historical total IDX market capitalization for a date range of up to 90 days.
- [Daily Full-Universe Index Close](https://docs.sectors.app/api-references/v2/indonesia/transaction/index-daily-universe.md): Returns the closing level of **every** IDX index on a single trading day in one call — instead of calling the per-index [Index Daily Transaction Data](https://docs.sectors.app/api-references/v2/indonesia/transaction/index-daily) endpoint once per index.
- [Index Daily Transaction Data](https://docs.sectors.app/api-references/v2/indonesia/transaction/index-daily.md): Returns daily closing price for a given IDX index over a date range of up to 90 days.
- [Top Company Movers](https://docs.sectors.app/api-references/v2/indonesia/ranking/top-changes.md): Returns top gainers and losers across multiple time periods. Supports two classifications (`top_gainers`, `top_losers`) and five periods (`1d`, `7d`, `14d`, `30d`, `365d`).
- [Most Traded Stocks](https://docs.sectors.app/api-references/v2/indonesia/ranking/most-traded.md): Returns the most traded IDX stocks by transaction volume over a date range of up to 90 days. Results are keyed by date.
- [Company IPO & Listing Performance](https://docs.sectors.app/api-references/v2/indonesia/ipo/listing-performance.md): Returns price change percentages since listing date for a given IDX-listed symbol, across 7, 30, 90, and 365-day windows.

- [Company Filings](https://docs.sectors.app/api-references/v2/indonesia/news/filings.md): Returns IDX insider trading filings — buy/sell transactions by company insiders and major shareholders. Supports filtering by sector, subsector, tags, symbol, transaction type, holder_type, and date range.
- [News Articles](https://docs.sectors.app/api-references/v2/indonesia/news/news.md): Returns paginated news articles from either the IDX (Indonesian Stock Exchange) or mining news sources. Use the `extension` parameter to choose the data source — each extension has its own set of valid filter parameters.
- [Stock Suspensions](https://docs.sectors.app/api-references/v2/indonesia/news/suspensions.md): Returns a paginated list of historical IDX-listed stock suspensions, including the date a stock was suspended, the official reason, and a link to the IDX PDF notice. Filter by `symbol` to look up a specific company's suspension history, or by `start` / `end` to scope to a date window.

Optionally filter to a single stock via `symbol`. Each entry in `data` lists every stock the broker touched that day with buy/sell/net values.

Optionally filter to a single broker via `broker_code`. Each entry in `data` lists every broker active on that day with buy/sell/net values, lots, frequency, and weighted avg price per share.

Use this as the authoritative source for valid broker codes when calling broker-scoped endpoints such as `/v2/broker-activity/{broker_code}/`.

- [SGX Companies Screener](https://docs.sectors.app/api-references/v2/singapore/screener/sgx-companies.md): High-performance API for filtering and sorting SGX-listed companies. Supports both structured SQL-like queries (`where`, `order_by`) and natural language queries (`q`). Returns a paginated list of companies.
- [List all SGX sectors](https://docs.sectors.app/api-references/v2/singapore/helper-list/sgx-sectors.md): Returns all available SGX sector slugs as a flat array.
- [SGX Subsectors](https://docs.sectors.app/api-references/v2/singapore/helper-list/sgx-subsectors.md): Returns all available SGX sector/subsector pairs as kebab-case slugs. Use these values as inputs to `sector` and `sub_sector` parameters.
- [SGX News Tags](https://docs.sectors.app/api-references/v2/singapore/helper-list/sgx-tags.md): Returns the complete list of distinct tag slugs found across all SGX news articles. Use these values with the `tags` parameter of the [SGX News](https://docs.sectors.app/api-references/v2/singapore/news/sgx-news) endpoint.
- [Full company report for an SGX-listed symbol](https://docs.sectors.app/api-references/v2/singapore/report/company-report.md): <Note>SGX symbol: 3-4 characters (letters or digits), optionally followed by `.SI` (case-insensitive) on input. E.g. `D05`, `U11`, `Z74`. Output always carries the `.SI` suffix.</Note>
- [SGX Share Buybacks](https://docs.sectors.app/api-references/v2/singapore/transaction/share-buybacks.md): Returns SGX share buyback records. Each row includes the purchase date, buyback type, price range, total value, total shares purchased, treasury shares after purchase, and mandate details.
- [SGX Daily Full-Universe Close](https://docs.sectors.app/api-references/v2/singapore/transaction/close.md): Returns the daily closing price for **every** SGX ticker on a single trading day, in one paginated feed — instead of calling the per-symbol [SGX Daily Price Data](https://docs.sectors.app/api-references/v2/singapore/transaction/daily) endpoint once per ticker.
- [SGX Daily Price Data](https://docs.sectors.app/api-references/v2/singapore/transaction/daily.md): Returns daily close price and volume for a given SGX-listed company over a date range of up to 90 days.
- [SGX Short Sell](https://docs.sectors.app/api-references/v2/singapore/transaction/short-sell.md): Returns SGX short sell data. Supports filtering by symbol and date range, and sorting via `order_by` (e.g. `start=2025-05-02&end=2025-05-02&order_by=-value` lists the most shorted stocks that day).
- [Top SGX companies by classification](https://docs.sectors.app/api-references/v2/singapore/ranking/top-companies.md): Returns top SGX-listed companies ranked by one or more classifications.
- [SGX Insider Filings](https://docs.sectors.app/api-references/v2/singapore/news/sgx-filings.md): Returns SGX insider trading filings — buy/sell transactions by company insiders and major shareholders. Supports filtering by symbol, transaction type, holder type, and date range.
- [SGX News](https://docs.sectors.app/api-references/v2/singapore/news/sgx-news.md): Returns paginated SGX news articles. Supports filtering by sector, sub-sector, tags, symbols, and date range.
- [List KLSE companies filtered by sector](https://docs.sectors.app/api-references/v2/malaysia/klse-companies.md): Returns all KLSE-listed companies in a given sector as `symbol` + `company_name` pairs.
- [Top KLSE companies by classification](https://docs.sectors.app/api-references/v2/malaysia/klse-top-companies.md): Returns top KLSE-listed companies ranked by one or more classifications.
- [Full company report for a KLSE-listed symbol](https://docs.sectors.app/api-references/v2/malaysia/klse-report.md): <Note>KLSE symbol: 4-digit numeric code. E.g. `1155`, `4197`, `5225`.</Note>
- [List all KLSE sectors](https://docs.sectors.app/api-references/v2/malaysia/klse-sectors.md): Returns all available KLSE sector slugs as a flat array.
- [List Mining Companies](https://docs.sectors.app/api-references/v2/mining/companies/mining-companies.md): Searches for Indonesian mining companies by name, symbol, slug, or key operation. Supports filtering by commodity type and company type.
- [Mining Company Detail](https://docs.sectors.app/api-references/v2/mining/companies/mining-companies-detail.md): Returns comprehensive operational details for a single mining company including activities, commodity types, licenses, contracts, and site count.
- [Mining Company Financials](https://docs.sectors.app/api-references/v2/mining/companies/mining-companies-financials.md): Returns annual financial records (assets, revenue, profit with breakdowns) for a mining company. All monetary values are in USD millions. Defaults to the latest available year.
- [Mining Company Ownership](https://docs.sectors.app/api-references/v2/mining/companies/mining-companies-ownership.md): Returns the corporate ownership tree for a mining company — showing parent companies (who owns it) and subsidiaries (what it owns) with percentage stakes.
- [Mining Company Performance](https://docs.sectors.app/api-references/v2/mining/companies/mining-companies-performance.md): Returns production volume, sales volume, strip ratio, and resources/reserves data for a mining company for a given year. Defaults to the latest available year.
- [List Commodities](https://docs.sectors.app/api-references/v2/mining/commodities-trade/commodities.md): Lists all commodities available in the price database with coverage metadata. Use this as a discovery endpoint before querying [Commodity Price History](https://docs.sectors.app/api-references/v2/mining/commodities-trade/commodity-price) endpoint.
- [Commodity Price History](https://docs.sectors.app/api-references/v2/mining/commodities-trade/commodity-price.md): Retrieves historical price data for a commodity by year range. Data is monthly (bi-weekly for recent Coal entries). Maximum range: 3 years.
- [Top Export Destinations](https://docs.sectors.app/api-references/v2/mining/commodities-trade/export-destination.md): Ranks countries by total export value for a given year and commodity, showing the top destinations for Indonesian commodity exports.
- [Global Commodity Data](https://docs.sectors.app/api-references/v2/mining/commodities-trade/global-commodity.md): Retrieves global commodity data including production, reserves, and trade information. At least one of `commodity_type` or `country` must be provided.
- [Company Sales Destinations](https://docs.sectors.app/api-references/v2/mining/commodities-trade/sales-destination.md): Retrieves sales destination breakdown for a specific mining company by its slug, showing revenue and volume distribution by country for a specific year. Defaults to the latest available year if none is specified.
- [Resources & Reserves Index](https://docs.sectors.app/api-references/v2/mining/sites-production/commodity-resources-reserves.md): Discovery index showing which provinces, years, and commodities have resources and reserves data available. Use this before querying the detail endpoint to confirm data availability.
- [Resources & Reserves Detail](https://docs.sectors.app/api-references/v2/mining/sites-production/commodity-resources-reserves-detail.md): Returns resources and reserves data for a single province, nested by year then by commodity. Each commodity entry contains the full breakdown: `exploration_target`, `total_inventory`, `resources`, `reserves`, and `unit`.
- [Mining Sites](https://docs.sectors.app/api-references/v2/mining/sites-production/mining-sites.md): Lists mining sites with advanced filtering for location, commodity type, and production volume, plus sorting capabilities and detailed site information.
- [Mining Site Detail](https://docs.sectors.app/api-references/v2/mining/sites-production/mining-site-detail.md): Returns full details for a single mining site by its slug, including parsed resources/reserves and location (with latitude and longitude).
- [Total Commodity Production](https://docs.sectors.app/api-references/v2/mining/sites-production/commodity-production.md): Returns total national production for a commodity across all years, including year-over-year percentage change. Results are ordered by year descending.
- [Mining Contracts](https://docs.sectors.app/api-references/v2/mining/licenses-auctions/mining-contracts.md): Returns active mining contracts linking mine owners to their service contractors. Optionally filter by owner or contractor slug.
- [Mining License Auctions](https://docs.sectors.app/api-references/v2/mining/licenses-auctions/mining-license-auctions.md): Lists mining license auctions scraped from the ESDM Minerba portal. Phases and participants are omitted from list results — use the detail endpoint for the full auction record.
- [Mining License Auction Detail](https://docs.sectors.app/api-references/v2/mining/licenses-auctions/mining-license-auctions-detail.md): Retrieves the full record for a single mining license auction by its WIUP code, including the parsed phases timeline and participant qualification list.
- [Mining Licenses](https://docs.sectors.app/api-references/v2/mining/licenses-auctions/mining-licenses.md): Lists mining licenses (IUP/IUPK) from the ESDM Minerba portal with filters for status, commodity, location, and expiry date.
